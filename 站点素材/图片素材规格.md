# 图片素材规格（画图前先看这张表）

想换掉网站现在默认的图标和背景，就把文件按下面的**文件名和尺寸**放进 `站点素材\` 目录，
然后双击 `生成网站.bat` + `一键发布.bat` 就行。

**全部都是可选的**：没放的自动用默认样式，不会报错。

>

---

## 一、放哪里、叫什么名字

```
站点素材\
├── 站标.png                ← 左上角「logo + 站名」整张图（可选）
├── 站标-深色.png           ← 站标的深色模式版（建议一起提供）
├── 网站图标.png            ← 浏览器标签页上的小图标
├── 背景-浅色.jpg           ← 浅色模式页面背景
├── 背景-深色.jpg           ← 深色模式页面背景
├── 背景.jpg                ← 可选：两模式共用（上面两个都没有时才用）
├── 学科图标\
│   ├── 语文.png  数学.png  英语.png  物理.png
│   ├── 化学.png  生物.png  其他.png  综合资料.png
│   └── （可选深色专用）语文-深色.png 等
└── 工具图标\
    ├── 重点总结器.png
    ├── 英语课助手.png
    └── （可选深色专用）重点总结器-深色.png 等
```

> 文件名必须**完全一致**（包括 `-浅色` `-深色` 这种连接符），否则不会被识别。

### 文件大小建议

| 素材 | 建议上限 |
| --- | --- |
| 网站图标 | 100 KB 以内（512×512 PNG 通常 30~80 KB） |
| 单张背景 | **300 KB 以内**（JPG 质量 80 左右，1920×1080 大约 200~400 KB） |
| 单个图标 | 20 KB 以内 |

> 背景太大拖慢首屏（服务器带宽只有 3 Mbps）。一张 300 KB 的背景 ≈ 0.7 秒。

## 三、怎么画才好看（重要）

### 1）网站图标（512×512）

- 画布正方形，**主体内容限制在中间 80% 区域**（即距边缘约 50px 内留空）
  —— iOS 主屏、部分浏览器会把四角裁圆，贴边的元素会被切掉
- 建议：纯色/渐变底 + 一个简洁的符号或单个汉字
- 透明底也可以，但如果背景完全透明，深色模式下浏览器的深色标签栏里可能看不清
  → **最稳的做法：自带一个不透明的圆角/圆形底**
- 用到的场合：浏览器标签页、收藏夹、手机添加到主屏

### 2）学科图标（88×88，显示 44×44）

- 页面会把它放进一个 **圆角 12px** 的方块里，所以图标自己**不要再画外框**
- 主体控制在中间 **72 × 72** 以内（四周各留 8px），避免被圆角切到
- 内容建议：**一个汉字**（语/数/英/物/化/生/其/综）或一个简笔符号；**不要写两个字**，44px 下会糊
- 颜色：卡片图标的底色是**很浅的蓝**（浅色模式）和**深蓝灰**（深色模式）。
  一张图两种模式都用，推荐用**中等明度、较高饱和**的颜色，例如：
  - 蓝 `#2F6DF6`、紫 `#7C3AED`、青 `#0891B2`、绿 `#16A34A`、橙 `#EA580C`、玫红 `#DB2777`
  - ❌ 避免：纯黑 `#000`、纯白 `#FFF`、极浅的灰（在一种模式下会消失）
- 想要绝对精准，就做两张：`语文.png`（浅色）+ `语文-深色.png`（深色，颜色调亮一档）

### 3）工具图标（80×80，显示 40×40）

- 规格同学科图标：圆角 11px，主体留 8px 边距
- 建议内容：`Σ`（重点总结）、`Aa`（英语课助手）这类**符号**，比汉字更清楚

### 4）背景（1920×1080 起）

- **文字会盖在上面**，所以背景必须**低对比、少细节**。推荐：
  - 大块浅色渐变、淡淡的水彩/纸张纹理、很浅的几何图形
  - ❌ 避免：照片、密集花纹、强对比条纹（会让文章很难读）
- 页面会自动叠一层**半透明遮罩**保证可读性：
  - 浅色模式：白色 82%
  - 深色模式：`#0F1218` 76%
  → 也就是说你的背景会被"冲淡"不少。**宁可画得比你以为的更浓一点**
- **中间约 880px 宽的区域是正文所在**，重要细节（比如图案）放在左右两侧更好
- 想做两种模式就给两张；只有一张的话两模式共用

### 5）深色/浅色模式的通用规则

| 情况 | 建议 |
| --- | --- |
| 只想做一套图标 | 用中等明度、饱和度高一点的颜色，两种模式都能看清 |
| 想要完美 | 每张图再做一份 `-深色.png`，深色下颜色调亮 20~30% |
| 背景 | **必须**分别做浅色和深色，否则一定有一边难看 |
| 网站图标 | 一张就够（浏览器不区分深浅），但要自带不透明底 |

## 四、改完怎么验证

1. 双击 `生成网站.bat`
2. 双击 `本地预览.bat`，在浏览器里点右上角的「◐」按钮切换浅色/深色，对比两种模式
3. 满意后双击 `一键发布.bat`

> 素材缺失或名字写错时，对应位置会自动用回默认样式（文字方块 / 无背景），不会报错。

## 五、当前默认样式（供参考）

| 位置 | 现在长什么样 |
| --- | --- |
| 网站图标 | 没有专门画，浏览器显示默认图标 |
| 学科图标 | 44×44 圆角方块，浅蓝底 + 学科名第一个字（如「化」），品牌蓝字 |
| 工具图标 | 40×40 圆角方块，浅蓝底 + 符号（`Σ` / `Aa`） |
| 页面背景 | 纯色（浅色 `#F4F6F9` 左右 / 深色 `#0F1218` 左右） |

## 六、站标（logo + 站名一张图）

左上角默认是「网站图标 + 文字」两部分。如果想自己设计成一张完整的图：

| 项 | 要求 |
| --- | --- |
| 文件名 | `站标.png`（深色模式版：`站标-深色.png`） |
| 画布 | 高 **104~160px**，宽 **300~600px**（显示高度 **48px**，手机 40px，宽度按比例） |
| 格式 | PNG，**透明底** |
| 留白 | 四周留 6~10px |
| 深浅 | **强烈建议两张**：浅色模式用深色文字、深色模式用浅色文字 |
| 上限 | 单张 150 KB 以内 |

放进去后，整个左上角会替换成这张图（不再显示图标和文字）。
详细步骤见同目录的 `站标-怎么换.txt`。
