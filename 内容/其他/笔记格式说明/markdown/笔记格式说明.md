# 笔记格式说明

本文件规定数学、物理、化学、生物四科笔记的统一格式. 所有后续笔记（含增补、修订）均按本说明书写. 凡本说明未覆盖的情形，以现有 `数学笔记.md`、`物理笔记.md`、`化学笔记.md`、`生物笔记.md` 的既有写法为准；既有写法与本说明冲突时，以本说明为准并回头修订笔记.

---

## 一、文件与文档结构

### 1.1 文件

- 文件为**纯 Markdown**，扩展名 `.md`，UTF-8 编码，简体中文.
- 数理化生公式统一用 `$…$`（行内）与 `$$…$$`（独立成行）书写的 LaTeX 片段.
- 文件**不设** `# 一级标题`. 文档直接从 `##` 开始，即顶层标题就是章节标题. 若某份笔记确需书名，另建封面文件，不写进正文.
- 四科笔记的文件名分别为 `数学笔记.md`、`物理笔记.md`、`化学笔记.md`、`生物笔记.md`.

### 1.2 标题层级

固定四级，不增不减：

| 层级 | 语法 | 用途 | 示例 |
| --- | --- | --- | --- |
| 第一级 | `## 零、…` / `## 一、…` / `## 二、…` | 章（大节） | `## 零、成绩组成`、`## 一、函数` |
| 第二级 | `### 1. …` | 节 | `### 1. 定义、名词和术语` |
| 第三级 | `#### 1.1 …` | 小节 | `#### 1.1 函数的定义` |
| 列表编号 | `**（1）…**：` | 并列条目 | `**（1）单调不减**：如果` |

层级规则：

1. 章用**中文数字**加顿号：`零、`、`一、`、`二、`……「零」专用于课程总览（成绩组成），正文各章从「一」开始.
2. 节用**阿拉伯数字**加点加空格：`### 1. 定义、名词和术语`，数字在**本章内**从 1 重新计.
3. 小节编号为 `节号.小节号`：`#### 1.1`、`#### 6.3`，在本节内连续，不得跳号.
4. **禁止跳级**：`##` 之后必须先是 `###`，不能直接出现 `####`. 不存在 `#####` 及更深层级；再往下分层时改用**（1）（2）（3）** 并列条目，或改用列表.
5. 标题文字**不加粗**（`##`/`###`/`####` 自带层级语义），标题末尾**不加标点**（不加句点、冒号）.
6. 编号与标题文字之间：`##` 用顿号，`###` 用点加空格，`####` 点后直接接文字（`#### 1.1 函数的定义`，编号与文字之间一个空格）.

### 1.3 何时使用 `####`

- 一节内部**只有一个论题**时，不设 `####`，节标题下直接写正文（例：`### 3. 函数的运算` 直接给出运算定义，再以 `#### 3.1 复合映射`、`#### 3.2 逆映射` 分列两个独立论题）.
- 一节内部有**两个以上平行论题**时，每个论题一个 `####`，编号连续（例：`#### 4.1`～`#### 4.4`）.
- 一节内既有总述又有平行论题时，总述写在 `###` 之下、第一个 `####` 之前（例：`### 4.` 之下先总述，再 `#### 4.1` …）.

### 1.4 章与节之间的分隔

- 相邻的 `##` 章之间**不加** `---` 分隔线；层级本身已足够清楚.
- 首个 `##` 之前不得有空标题、目录或说明段.
- 若确需在章首列本节导航（如「本节依次讨论……」），写成普通段落，不写成列表，不写成引用块.

---

## 二、段落、空行与间距

1. **标题前后各留一个空行**，标题行本身单独占一行.
2. **独立公式（`$$…$$`）单独成行，其前后各留一个空行**，公式行内不得混入中文或标点.
3. 段落之间留一个空行；同一段落内不硬换行.
4. 行内公式与相邻中文文字之间加一个半角空格（`设 $f:A\to B$，则`），公式与公式之间用顿号、逗号或「，」连接.
5. 连续两个独立公式（如「倒数关系」与「平方关系」）之间用一个空行隔开，并在各自之前各写一行提示语（`倒数关系：`、`平方关系：`）.
6. 行尾不得留多余空格（Markdown 硬换行符）；不使用 `<br>`.
7. 不使用分隔线 `---`、不使用表格（除非是纯对照性内容，如本说明第 4.1 节的记号总表与第十一节的索引表，以及生物学中的实验阶段对照表、结构与功能对照表）、不使用代码块，以保持版面朴素一致.**举例（例题）与证明一律用引用块 `>` 包裹**，写法见第六节.（本说明文件自身为便于分区使用了 `---` 与代码块，这属于**说明文档**的写法，笔记正文不得照搬.）
8. **插图照常保留**：笔记可以插入图片，写法为 `![图片说明](地址)`，地址可以是本地相对路径或图片链接. 图片单独成段，其前后各留一个空行；`[]` 内必须写有意义的图片说明（不得写 `image.png`、`1` 这类无意义文字）. 正文引用某张图时用「图」指代（如「图上的正负号表示……」），并在图的前后配上文字说明该图表达的内容；几何图形、示意图等最好同时用文字、记号与公式叙述清楚（如「以圆心、半径与过半径端点的切线围成的三角形」），以便脱离图片也能读懂.

## 三、命题的书写

### 3.1 定义与结论的标准句式

定义、判定与结论一律采用**「条件句 + 结论句」**两段式，中间用独立公式隔开：

```
设 <对象与前提>. 如果

<条件，独立公式或行内公式>

则称 <对象> 为 <术语>，记为

<记号，独立公式>

<必要时补一句补充说明.>
```

**范例（有界性）**：正文中实际写法为

```
设 $f:A\to R$. 如果

$$\exists m>0,\ \forall x\in A,\quad |f(x)|\leq m$$

则称 $f$ 在 $A$ 上**有界**，否则称 $f$ 在 $A$ 上**无界**.
```

（上例用代码块仅为展示原文，实际笔记中不套代码块.）

规则：

1. 被定义或被命名的术语**一律加粗**（`**映射**`、`**有界**`、`**收敛**`），同一术语在全文的加粗方式保持一致.
2. 命名句统一用「称……为……」「称……是……」「记为……」「记作……」，不混用「叫做」「叫做为」「命」.
3. 「记为 / 记作 / 定义」之后必须是独立公式行，公式行末**不加标点**.
4. 「则称」句末尾用英文句点 `.`；「否则称……」与「则称」句之间用逗号，并在同一行内写完.
5. 前提中的符号引入要完整：先写「设 $f:A\to R$」，再写条件；不得在条件里首次出现未说明的符号.
6. 定义、术语或记号之后的**直观解释句**一律以「这意味着：」结尾，再另起一段写解释内容，不把解释塞在同一行：

```
则称当 $x\to x_0$ 时，$f(x)$ 为**无穷小量**，这意味着：

当 $x\to x_0$ 时，$|f(x)|$ 很小，而且要多小有多小.
```

若以记号本身作主语（如 `$a=\displaystyle\lim_{x\to x_0}f(x)$ 意味着：`），同样在「意味着：」之后另起一段. 一处写了直观解释句，则与之并列的各情形都要写，「这意味着：」与换行的写法也要一致.

7. **承接公式的「即」「其中」单独成行**：凡承接上一个独立公式的「即」「其中」，都另起一行、其后不加标点，再写内容：「即」之后接公式时，公式独立成行；「即」之后接短句时，短句另起一行. 若「即」是句中成分（如「即 $\{a_n\}$ **有界**.」），才与前后文字写在同一行.

```
即

$$f(x)=f(x_0)+o(1),\qquad x\to x_0$$

其中 $g$ 刻画了 $f(x)$ 与 $f(x_0)$ 的偏差.
```

### 3.2 名词列举

名词、术语、要素的罗列用无序列表，格式为

```
- <记号>：<名称>；
- <记号>：<名称>.
```

即：冒号用全角「：」，中间各项以分号「；」结尾，**最后一项以英文句点 `.` 结尾**. 示例见 `数学笔记.md` 的「1.2 名词和术语」.

### 3.3 并列条目编号

同一论题下的**并列定义或并列情形**用 `**（1）名称**：` 形式，编号用全角括号加阿拉伯数字：

```
**（1）单调不减**：如果

<公式>

则称 $f$ 在 $A$ 上**单调不减**.

**（2）严格单调增**：如果
...
```

规则：

- 编号后紧跟术语，术语加粗；编号与术语之间不加空格.
- 冒号用全角「：」.
- 各条目之间留一个空行.
- 并列条目**结束时**若有统称、归纳，另起一条 `**（n）统称**：` 或直接写普通段落.

### 3.4 禁止的写法

- 不写「定义 1.1」「定理 2.3」「命题 3.1」这类编号标签（本笔记体系用小节编号定位）.
- 引用块用于举例（例题）、证明，以及与正文分开的「注意」「说明」（见第六节）；引用块内的标签一律加粗，写作 `> **例**：`、`> **证明：**`、`> **注意**：`；这三类以外的正文不进引用块.
- 不用「证明如下」「证明过程略」等口语化提示，统一写 `**证明：**`（冒号用全角）.
- 不在正文中出现 HTML 标签，也不使用 MDX 容器语法（如 `::::info[…]`、`:::note` 等）；需要提示时改用引用块（见第六节）.

### 3.5 外文人名命名的定理、实验与结构

以外文人名音译命名的定理、引理、法则、公式，以及生物学中以人名命名的实验、定律、细胞与结构，第一次出现（含标题）时，在音译后括注原文，再写类别，如

- 费马（Fermat）引理；
- 罗尔（Rolle）定理；
- 拉格朗日（Lagrange）中值定理；
- 柯西（Cauchy）中值定理；
- 洛必达（L'Hôpital）法则；
- 泰勒（Taylor）公式；
- 巴甫洛夫（Pavlov）条件反射实验；
- 施旺（Schwann）细胞.

后文引用这些定理时，只写「原文＋类别」，不再写中文音译，如「由 Fermat 引理」「由 Rolle 定理」「由 L'Hôpital 法则」；生物学名词同此，如「Pavlov 实验」「Schwann 细胞」. 人名用于非定理术语（如皮亚诺（Peano）余项、拉格朗日（Lagrange）余项）时，首次出现同样在音译后括注原文，后文写「原文＋术语」，如「Peano 余项」「Lagrange 余项」「Taylor 展开式」. 中英文之间须加半角空格.

## 四、记号与公式

### 4.1 数学记号总表

全文必须逐字一致，不得出现同义不同写：

| 项目 | 统一写法 | 禁止写法 |
| --- | --- | --- |
| 集合 | $A,B,C$ | — |
| 实数集 / 数集 | $R$ | $\mathbb{R}$（与现有笔记保持一致） |
| 维欧氏空间 | $R^n$ | $R^N$、$\mathbf{R}^n$ |
| 正整数集 | $N^+$ | $N^*$、$\mathbb{N}^{+}$ |
| 整数集 | $Z$ | $\mathbb{Z}$ |
| 属于、任意、存在 | $\in$、$\forall$、$\exists$ | `in`、`any` |
| 蕴含 | $\Rightarrow$ | `=>`、`->`（文字性蕴含场合） |
| 趋于 | $\to$ | `->`、$\rightarrow$、`-->` |
| 小于等于 / 大于等于 | $\leq$ / $\geq$ | `<=`、`>=` |
| 绝对值 | $|x|$、$|f(x)-a|$ | `abs()`、`\lvert`/`\rvert` 与 `|` 混用 |
| 定义域 / 值域 | $D_f$ / $R_f$ | $D_mf$、$R_gf$、$Dom f$ |
| 图象 | $graph_f$ | $Graph_f$、$\mathrm{graph} f$ |
| 复合 | $g\circ f$ | $gf$、$g(f)$ |
| 逆映射 | $f^{-1}$ | $f'$、$inv(f)$ |
| 反三角函数 | $\arcsin$、$\arccos$、$\arctan$、$\operatorname{arccot}$ | $\text{arccot}$、$arccot$、$\mathrm{arcsin}$ |
| 正切 / 余切 / 正割 / 余割 | $\tan$、$\cot$、$\sec$、$\csc$ | $tg$、$ctg$、$Tan$ |
| 双曲函数 | $\sinh$、$\cosh$ | $sh$、$ch$、$Sinh$ |
| 极限 | $\lim_{n\to\infty}$、$\lim_{x\to x_0}$ | $lim$、$\mathrm{lim}$ |
| 左 / 右极限 | $f(x_0^-)$、$f(x_0^+)$ | $f(x_0-)$、$f(x_0+)$ |
| 无穷 | $+\infty$、$-\infty$、$\infty$ | $+inf$、`inf` |
| 希腊字母 φ | $\varphi$ | `\phi`（除特别说明外一律不用） |

补充规则：

1. 不等号一律用 `\leq`、`\geq`，全文不允许出现 `<=`、`>=`.
2. 趋于记号一律用 `\to`；数列极限写 $\lim_{n\to\infty}$，函数极限与无穷远写 $\lim_{x\to+\infty}$、$\lim_{x\to-\infty}$；同一小节内写法统一.
3. 极限号后**必须**接等号：写 $\lim_{n\to\infty}a_n=a$，不得写 $\lim_{n\to\infty}a_n\to a$.
4. 指数的三角函数写 $\sec^2x$ 而不是 $\sec ^2x$；反三角函数名的正体用 `\operatorname{arccot}`.
5. 向量、点等需要强调时用 `\mathbf{x}`，并在首次出现处说明.
6. 希腊字母 φ 一律写 `\varphi`（如 $\varphi$、$\varphi_0$、$\Delta\varphi$），不使用 `\phi`；相位、角度、球坐标中的方位角及一般辅助函数名等均照此办理. 若某处确需使用 `\phi`，必须在笔记正文或本说明中特别说明，并且同一份笔记内不得混用两种写法.

### 4.2 分式：统一用 `\dfrac`（指数除外）

- **全文分式一律用 `\dfrac`**，独立公式行与行内公式皆然：`$$\csc x=\dfrac{1}{\sin x}$$`、`$|b_n|<\dfrac{\epsilon}{2}$`.
- **唯一的例外是指数（上标）中的分式**：用 `\frac` 写成小号分式，如 `$3^{\frac{1}{n}}$`、`$\left(\dfrac{n}{2}\right)^{\frac{n}{2}}$`、`$\left(\dfrac{n}{2}\right)^{\frac{n+1}{2n}}$`；底数与一般分式仍用 `\dfrac`.
- 除指数外不得出现 `\frac`（统一改为 `\dfrac`，**含嵌套分式的内层**，不得出现 `\dfrac{…\frac{…}…}` 这种内外不一致的写法）.
- 分式较长、会影响行内行距时，宁可改写为独立公式行，也不改用 `\frac` 缩小分式.
- **函数名可以用斜杠简写，函数值一律写分式**：作函数名时写 `f/g`（如 `$f/g$ 在 $x_0$ 点连续`、`$(f/g)(x)$`），一旦写出函数值的算式，就一律用 `\dfrac`：`$\left(\dfrac{f}{g}\right)(x)=\dfrac{f(x)}{g(x)}$`. 同一个式子里不得出现「$\left(\dfrac{f}{g}\right)(x)=f(x)/g(x)$」这类斜杠与分式混用的写法.

### 4.3 公式内的分隔与对齐

- 同一行并列两个公式时用 `\qquad` 分隔：`$$\lim_{n\to\infty}a_n=a\qquad\text{或}\qquad a_n\to a$$`
- 公式内的条件、限定用 `\quad` 或 `\qquad` 分隔，用 `,` 或 `;` 断句：`$$|a_n-a|<\epsilon,\qquad \forall n\geq N$$`
- 公式内不允许出现中文，需要文字时用 `\text{…}`：`$$\sinh x=\dfrac{e^x-e^{-x}}{2}\quad(\text{奇函数})$$`
- 公式内不允许出现 `\dfrac` 之外的分式写法（如 `a/b`），也不允许出现 `\times` 与 `\cdot` 混用；乘法在数值连乘时用 `\times`，符号相乘用省略写法（`(fg)(x)=f(x)g(x)`）.
- 省略号用 `\dots`（列举）或 `\cdots`（运算连加连乘），不得用 `...`.
- **行内公式中的极限号一律写 `\displaystyle\lim`**：写在 `$…$` 内时，为使下标落在极限号正下方，统一加 `\displaystyle`；独立公式行内直接用 `\lim`，不得加 `\displaystyle` 或 `\limits`. 全文不得出现 `\lim\limits`：

```
$a=\displaystyle\lim_{x\to x_0}f(x)$ 意味着：

$$a=\lim_{x\to x_0}f(x)\qquad\text{或}\qquad f(x)\to a\ (x\to x_0)$$

由 $\displaystyle\lim_{x\to x_0}f(x)=0$ 得……
```

### 4.4 独立公式与行内公式的选择

- **定义、记号、结论、条件式**：独立成行（`$$…$$`）.
- **正文中的引用、说明、代入**：行内（`$…$`）.
- 判断标准：该式子是否需要被单独引用、是否承载定义功能. 承载定义功能的一律独立成行.

### 4.5 物理记号与单位

- 物理量符号用斜体：$L$、$l$、$n$、$u$、$\beta$、$\sigma$.
- **单位一律用正体**，写在 `\text{}` 内：$\text{nm}$、$\text{pm}$、$\text{J}$、$\text{m}^{-1}$；不得写成斜体的 `$m^{-1}$`.
- 数值与单位之间空一个 `\,`（如 $2.179\times 10^{-18}\,\text{J}$）；单位也可以写在公式外作普通文字（如 `52.9 pm`），但同一份笔记内要统一.
- 数量级连乘用 `\times`（如 $3\times 10^{8}$），符号相乘省略写法或用 `\cdot`.
- 物理量的定义式、结论式按 4.4 独立成行；同一行并列两个公式时用 `\qquad` 分隔.

### 4.6 化学记号

- 元素符号、原子轨道、电子层与亚层、族号等一律用正体，写在 `\text{}` 内：$\text{Cr}$、$\text{1s}^2\text{2s}^2\text{2p}^2$、$\text{3d}^5\text{4s}^1$、$\text{VIIB}$、$\text{Pd}$.
- 量子数用斜体小写字母：$n$、$l$、$m$、$m_s$；能级角标用斜体下标（如 $E_{4s}$）.
- 化学式内部不留空格；上下标紧跟正体符号之后（`$\text{3d}^{10}$` 而不是 `$3d^{10}$`）.
- 「转化为」与化学方程式中的箭头统一用 `\to`，不用 `->`.

### 4.7 生物记号与术语

- 生物学术语（结构、细胞器、过程、激素、疾病等）首次出现**加粗**，后文沿用同一名称且不再加粗. 同一概念不得混用两个名称（如「细胞外液」与「内环境」只取一个为主，另一个在首次出现处注明同义）.
- **拉丁学名用斜体**：属名首字母大写、种加词小写，如 *Homo sapiens*、*Escherichia coli*；首次出现写「中文名（学名）」，如 人（*Homo sapiens*）、大肠杆菌（*Escherichia coli*），后文只写中文名.
- **基因与基因型用斜体**：等位基因写 $A$、$a$，基因型写 $Aa$、$X^B Y$（整段斜体）；表现型用中文正体（如「红眼」）；蛋白质名用正体（如「血红蛋白」「RNA 聚合酶」），以与基因名区分.
- 生物笔记中的**化学式、离子与分子名**按 §4.6 用 `\text{}` 正体：$\text{Na}^+$、$\text{K}^+$、$\text{Cl}^-$、$\text{Ca}^{2+}$、$\text{CO}_2$、$\text{O}_2$、$\text{H}_2\text{O}$、$\text{ATP}$、$\text{ADP}$、$\text{DNA}$、$\text{RNA}$；不得写成 `$Na^+$`、`$CO_2$` 这类斜体写法.
- **反应式与流程中的箭头**统一用 `\to`：如 $\text{ATP}\to\text{ADP}+\text{Pi}$；描述「导致、转变为」的行文同样用 `\to`，不得出现 `->`、`=>`、`→`、`➔`.
- **单位与数值**：温度、渗透压、电位等量的单位用正体（`\text{℃}`、`\text{kPa}`、`\text{mV}`、`\text{nm}`），数值与单位之间空一个 `\,`，如 $37\,\text{℃}$、$770\,\text{kPa}$、$-70\,\text{mV}$；pH 写作正体 $\text{pH}$，范围写 $7.35\sim7.45$；不得写成 `pH7.35-7.45`、`770KPa`、`-70mV`.
- 生物学中**只用于纯对照**的内容（如实验各阶段对照、两类结构的组成与功能对照）可以用表格，写法同 §2.7；其余内容不得用表格罗列.
- 插图按 §2.7 书写. 原笔记中只标「（图）」而尚无图片地址的位置，本次整理**暂时保留「（图）」占位**，补图后须按 §2.7 改写为「……如图所示：」+ 图片 + 文字说明；定稿前不得留占位.

## 五、证明的书写

1. 证明整体用引用块包裹（见第六节），块内以 `**证明：**` 起头，单独成段，冒号为全角.
2. 证明结束另起一段，写「原命题得证.」或「命题得证.」，不使用 `□`、`■`、`QED`、`∎`.
3. 分步证明用 `**第一步（步骤名）**：`、`**第二步（步骤名）**：`，步骤名用 2～6 字概括（如「化为零极限」「控制尾部」「控制首部」「合并」）.
4. 每一步单独成段，步骤内先交代前提，再给公式，最后给结论.
5. $\epsilon$-$N$ 与 $\epsilon$-$\delta$ 论证必须写明：$\epsilon$ 的取法、$N$（或 $\delta$）的存在性与来源、适用范围（$n\geq N$、$0<|x-x_0|<\delta$）.
6. 引用前面已给的定义、结论时，用「由……得」「因为……所以……」的完整句式，并指明依据（如「由于 $b_n\to 0$」）.
7. 证明以必要为度：简单或考试不常考的结论可以不写证明，只保留结论；不得用「类似可证」「读者自明」「证明略」等代替证明.

## 六、引用块：例、证明、注意与习题

**举例（例题）、证明、注意与习题一律用引用块 `>` 包裹**，与正文明确分开；引用块与前后正文之间各留一个空行.

规则：

1. 引用块每行都以 `> ` 起头；块内的空行写成单独一行 `>`.
2. 块内仍遵守本说明的全部规则：独立公式写成 `> $$…$$`，并在其前后各写一行 `>`；块内的列表、加粗、标点照常.
3. 例题以 `> **例**：` 起头，冒号为全角，解答与题目同处一个引用块内（题目与解答之间用单独一行 `>` 分隔，不另起引用块）.
4. 证明以 `> **证明：**` 起头并单独成段，结尾的「原命题得证.」也写在块内、单独成段.
5. 引用块内不出现标题（`#`）；需要分步时用 `**第一步（步骤名）**：`.
6. 正文中一句话带过的「例如……」属于行文，不另设引用块；凡独立成段、给出具体对象或算式的举例（例题），都必须用引用块.
7. 同一段举例内部不再嵌套引用块.
8. 「注意」「说明」等需要与正文分开的提示也用引用块，标签写作 `> **注意**：`.
9. 习题与题解同样用引用块：题目以 `> **题**：` 起头；解答紧接在同一引用块内、另起一段，以 `> **解**：` 起头（证明题写 `> **证明：**`）. 若干并列小题可以各占一个引用块，也可以在同一块内写成编号列表.

范例（本说明用代码块展示原文，实际笔记中不套代码块）：

```
> **例**：求碳原子 $\text{2p}$ 电子的屏蔽常数.
>
> 碳原子的电子排布为 $\text{1s}^2\text{2s}^2\text{2p}^2$，故
>
> $$\sigma=3\times 0.35+2\times 0.85=2.75$$
>
> $$Z^*=Z-\sigma=6-2.75=3.25$$
```

证明的写法：

```
> **证明：**
>
> 设反射面为 $x$ 轴，……
>
> 因为 $\alpha$、$\beta$ 均为光线与法线的夹角，都取锐角，所以 $\alpha=\beta$，即入射角等于反射角.
>
> 原命题得证.
```

## 七、标点与空格

1. **句末一律用英文句点 `.`**：全文不出现中文句号（Unicode 码位 U+3002，字形「．」的圆形句号）；句点后若紧接中文字符，须加一个半角空格，例如「则称 $f$ 为**函数**. 若 $B$ 是数集……」.
2. **句点后紧接中文标点时一律不加空格**：句点后若是「，」「；」「：」「、」、右括号「）」或右引号「」」，直接相连，不插入空格（如「……一致.（本说明……）」）.
3. **句中停顿用全角逗号「，」**：行列内顿号「、」、分号「；」、冒号「：」、括号「（）」照常使用. 只有句末标点改用 `.`，句中标点保持全角中文标点.
4. **行内公式后若句子未完**，用「，」；**句子结束**用 `.`；**列举项之间**用「；」，列表末项用 `.`.
5. **独立公式行末不加任何标点**，句子的标点由紧随其后的文字承担.
6. **代码片段内不受标点规则约束**：反引号包围的 `…` 与代码块中按原文照录，可含 `.`、`\`、空格等，不适用本条.
7. 中文与相邻英文、数字或行内公式之间加一个半角空格；中文标点与公式之间不强制加空格.
8. 数学表达式内部一律用半角（`,`、`;`、`(`、`)`），与中文标点不混用.

## 八、对称情形的写法（强制）

同一论题下互为对称的若干情形（如左极限与右极限、正无穷远点与负无穷远点、单调不减与单调不增、极小值与极大值），**只保留其中一部分**，其余情形不再逐条重复，统一用「其余情形依次类推」交代.

规则：

1. 保留的部分一般取「正向」或「第一组」情形，如只写右极限、正无穷远点、单调不减与严格单调增、极小值与严格极小值.
2. 「依次类推」之前必须写明由已写情形得到其余情形的替换规则：改变哪个不等号、替换哪个记号、极限过程如何变化.
3. 不得只写「类似地」「同理可得」而不交代替换规则，也不得把对称情形逐条重复写出.
4. 对称情形之后的统称、关系与推论（如左、右极限与极限的关系）仍须完整写出.
5. 若某情形经变量替换可直接得到且无独立记号，可写「其余情形依次类推」并给出替换式，但不得只写「同理」.

范例：

```
**（1）右极限**：设 $f:(x_0,x_0+\delta_0)\to R,\ a\in R$. 如果对于任意 $\epsilon>0$，存在 $0<\delta<\delta_0$，使得

$$|f(x)-a|<\epsilon,\qquad \forall 0<x-x_0<\delta$$

则称 $a$ 是 $f$ 在 $x_0$ 点的**右极限**，记为

$$a=\lim_{x\to x_0^+}f(x)\qquad\text{或}\qquad a=f(x_0^+)$$

**（2）左极限**：左极限的定义依次类推（把（1）中的定义域 $(x_0,x_0+\delta_0)$ 改为 $(x_0-\delta_0,x_0)$、条件 $0<x-x_0<\delta$ 改为 $0<x_0-x<\delta$，并把记号 $x_0^+$ 改为 $x_0^-$）.
```

## 九、内容范围

1. 笔记只记录**原笔记已有的**定义、定理、推导与结论.
2. 修订时不得新增原笔记没有的命题、例子、证明或恒等式；**唯有第八节允许的对称情形缩写与用户明确要求的补全**属于允许的扩充.
3. 发现原笔记存在错误时（符号错、定义域错、条件缺失、记号矛盾），必须改正并在改动处保持排版格式不变.
4. 修订后若删除了某些原有记号，须检查全文是否仍有残留引用（如删掉 $\text{arccot}$ 后不得再有 `\text{arccot}`）.

## 十、完整范例（可作为模板复制）

```
### 6. 函数的极限

#### 6.1 定义和记号

设 $f:(x_0-\delta_0,x_0+\delta_0)\backslash\{x_0\}\to R,\ a\in R$. 如果对于任意 $\epsilon>0$，存在 $0<\delta<\delta_0$，使得

$$|f(x)-a|<\epsilon,\qquad \forall 0<|x-x_0|<\delta$$

则称 $a$ 是 $f$ 在 $x_0$ 点的**极限**，记为

$$a=\lim_{x\to x_0}f(x)\qquad\text{或}\qquad f(x)\to a\ (x\to x_0)$$

$a=\displaystyle\lim_{x\to x_0}f(x)$ 意味着：当自变量 $x$ 趋近于 $x_0$ 且 $x\neq x_0$ 时，函数值 $f(x)$ 与 $a$ 很接近，而且要多接近有多接近.

#### 6.2 左极限和右极限

**（1）右极限**：设 $f:(x_0,x_0+\delta_0)\to R,\ a\in R$. 如果对于任意 $\epsilon>0$，存在 $0<\delta<\delta_0$，使得

$$|f(x)-a|<\epsilon,\qquad \forall 0<x-x_0<\delta$$

则称 $a$ 是 $f$ 在 $x_0$ 点的**右极限**，记为

$$a=\lim_{x\to x_0^+}f(x)\qquad\text{或}\qquad a=f(x_0^+)$$

**（2）左极限**：左极限的定义依次类推（把（1）中的定义域 $(x_0,x_0+\delta_0)$ 改为 $(x_0-\delta_0,x_0)$、条件 $0<x-x_0<\delta$ 改为 $0<x_0-x<\delta$，并把记号 $x_0^+$ 改为 $x_0^-$）.
```

要点回顾：`### 节` → 空行 → `#### 小节` → 空行 → 前提句「设……」 → 空行 → 条件公式（独立行） → 空行 → 结论句「则称……」 → 空行 → 记号公式（独立行） → 空行 → 直观解释段.

## 十二、定稿前检查清单

1. 顶层是否从 `##` 开始，是否误加了 `#` 总标题或 `---` 分隔线.
2. 标题层级是否严格为 `##` → `###` → `####`，有无跳级、有无漏号.
3. 节号是否在本章内从 1 连续编号；小节号是否为「节号. 序号」且连续.
4. 每条定义是否都是「设……」+ 条件公式 + 「则称……」+ 记号公式的结构.
5. 被定义的术语是否全部加粗，且同一术语加粗方式一致.
6. 句末标点是否一律为英文句点 `.`，有无中文句号「。」残留；句点后接中文字符时是否补了半角空格；行内公式后标点是否为全角.
7. 公式与相邻中文文字之间是否保留一个半角空格；行尾是否无多余空格.
8. 分式是否一律用 `\dfrac`（无 `\frac` 残留；注意嵌套分式的内层也要用 `\dfrac`，例如
   `$$\left|\dfrac{b_N+\cdots+b_n}{n}\right|\leq\dfrac{(n-N+1)\times\dfrac{\epsilon}{2}}{n}<\dfrac{\epsilon}{2}$$`
   而不是内层写 `\frac`）；**指数（上标）中的分式例外，应写 `\frac`**.
9. 记号是否与第 4.1 节总表逐字一致（重点查 `<=`、`\rightarrow`、`N^*`、`x_0-`/`x_0^-`、`\text{arccot}`）.
10. 极限号后是否一律为等号，无「$\lim\cdots\to$」写法.
11. 直观解释句是否都写成「这意味着：」+ 另起一段；已写出的并列情形是否都写了直观解释句，写法是否一致.
12. 承接独立公式的「即」「其中」是否都单独成行、其后不加标点；句中成分的「即」是否仍在行内.
13. 行内极限号是否都写 `\displaystyle\lim`，独立公式行是否都写 `\lim`，有无 `\lim\limits` 残留.
14. 对称情形是否只保留其中一部分，其余是否用「其余情形依次类推」交代，替换规则是否写明；有无只有「类似」「同理」而无替换规则的写法.
15. 举例（例题）、证明、注意、习题是否都用引用块包裹，块内每行是否都带 `>`，块内公式与空行是否按第六节书写，标签（`**例**`、`**证明**`、`**注意**`、`**题**`、`**解**`）是否加粗.
16. 证明是否以 `**证明：**` 开始、以「原命题得证.」结束，分步是否用「第一步（……）」；按规定省略的证明是否已删去，省略处是否只保留结论.
17. 是否新增了原笔记没有的内容（只允许第八节允许的对称缩写与用户明确要求的补全）.
18. 术语是否首次出现即交代清楚，后续是否始终沿用同一术语.
19. 物理量的单位是否为正体（`\text{m}^{-1}`、`\text{J}`、`\text{nm}`），有无斜体单位残留.
20. 化学符号（元素、原子轨道、电子层与亚层、族号）是否用 `\text{}` 正体，量子数是否用斜体 $n$、$l$、$m$、$m_s$.
21. 插图是否单独成段、前后各留一个空行；`![…](…)` 中 `[]` 内的图片说明是否有意义（不得写 `image.png`、`1`）；图的前后是否配有文字说明，正文是否用「图」指代.
22. 该处是否属于「一句话带过的例如」，若已独立成段给出具体对象或算式，是否已改用引用块.
23. 文件名与编码是否为 UTF-8 的 `.md`.
24. 希腊字母 φ 是否一律写 `\varphi`，有无 `\phi` 残留（除特别说明的场合外）.
25. 外文人名命名的定理、引理、法则、公式，首次出现是否写成「音译（原文）＋类别」，后文引用是否写成「原文＋类别」，中英文之间是否加空格.
26. 简单或考试不常考的证明是否已省略；省略处是否只保留结论，没有「证明略」「读者自明」「类似可证」等字样.
27. 生物学术语是否首次出现即加粗、后文沿用同一名称；同一概念有无两个名称混用.
28. 生物学中的化学式、离子与分子名是否用 `\text{}` 正体（如 $\text{Na}^+$、$\text{CO}_2$），有无 `$Na^+$`、`$CO_2$` 残留.
29. 反应式与流程箭头是否统一用 `\to`，有无 `->`、`=>`、`→`、`➔` 残留.
30. 温度、渗透压、电位等是否写作正体单位并留 `\,`（如 $37\,\text{℃}$、$770\,\text{kPa}$、$-70\,\text{mV}$），pH 是否写作正体 $\text{pH}$ 且范围用 $\sim$.
31. 拉丁学名、基因与基因型是否用斜体，中文名后是否括注学名；蛋白质名是否为正体.
32. 生物学中的表格是否只用于纯对照性内容；正文是否残留「（图）」占位或 MDX 容器（`::::info` 等）.
